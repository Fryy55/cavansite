# Separator
`Separator` is a simple visual separator. It is responsive to layouts and dynamic resizing, and comes in 2 orientations - horizontal and vertical - which matter for fade direction and which dimension is considered to be width

![Separator](../.images/Separator.png)

There is a number of getters/setters for fade length, color and width which control the longest the fade will get when counting from the "edge" of the separator, its color and dimension perpendicular to the fade direction respectively. All getter/setter names are `getFadeLength`, `setFadeLength`, `getColor`, `setColor`, `getWidth` and `setWidth`
